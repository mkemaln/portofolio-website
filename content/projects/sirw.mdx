SIRW is a website built for an easier administration and information system within the RW environment. It is capable of managing citizen data, social assistance (bansos), and publishing news or announcements.

## My Contribution

- Developed the frontend interface using TailwindCSS.
- Built the backend system using PHP Laravel Framework.
- Implemented a responsive design to enhance user experience on various devices.
- Configured the VPS environment with necessary software and dependencies for the web servers.
- Implementing auto deployment using github workflow to accelerate the development process.
