HRIS is a website worker management application for HR. This website is focused on managing employees, attendance, payroll and leave for employees company. 
HRIS is developed in a cooperation between JTI Polinema and PT cmlabs Indonesia Digital.

- Responsible for team management and task distribution among team members.
- Built API-based backend systems using the Laravel framework.
- Responsible for CI/CD and server configuration to optimize development efficiency.
